Common questions

How is this different from the CLI?

The CLI is free and always will be. The dashboard adds a web UI, multi-instance management, scheduled sync, team collaboration, and audit logs — things you can't do from a terminal alone.

Do I need the CLI to use the dashboard?

No. The dashboard connects directly to your n8n instances via API. The CLI is a separate tool for local/Git-based workflows.

Is my n8n API key safe?

API keys are encrypted at rest and never exposed in the UI. All connections use HTTPS.

Can I cancel anytime?

Yes. No contracts, no commitment. Cancel from your dashboard and your data is exportable.

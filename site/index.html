n8n-sync

Git-friendly version control for n8n Community Edition workflows. Pull, push, diff, and drift detection — no Enterprise required.

pip install n8n-sync

Commands

n8n-sync init

Interactive setup wizard

n8n-sync pull

Export workflows to normalized JSON files

n8n-sync push

Create/update workflows on remote

n8n-sync diff

Show semantic local vs remote differences

n8n-sync status

List workflows with drift detection

n8n-sync list

Show remote workflows with IDs & tags

Why n8n-sync?

📝

Readable Git diffs

YAML frontmatter + sorted JSON = stable, meaningful diffs

🔑

Credential mapping

Staging → production without manual fixes

🔄

CI integration

diff --check exits 1 on drift, 0 if in-sync

🛡️

Drift detection

Know if someone changed a workflow in the UI

👀

Dry-run push

Preview changes before applying them

🆓

No Enterprise required

Works with any Community Edition instance

n8n-sync

Free open-source CLI that puts your n8n workflows under Git version control. Backup, diff, sync, and detect drift — without Enterprise.

Lost a workflow? Can't diff changes? No CI/CD for automations?
That's the problem n8n-sync solves.
pip install n8n-sync

What people use it for

Backup to Git

n8n-sync pull exports all workflows as readable JSON files. Commit them. You now have history, rollback, and audit trail.

CI/CD for automations

n8n-sync diff --check exits 1 if local and remote differ. Run it in GitHub Actions to catch drift before it causes incidents.

Staging → Production

Push workflows from staging to production with automatic credential mapping. No manual fixes.

Multi-instance sync

Manage multiple n8n instances from one Git repo. Filter by pattern: n8n-sync pull --filter "prod-*"

Commands

n8n-sync init

Interactive setup wizard

n8n-sync pull

Export workflows to normalized JSON

n8n-sync push

Create/update workflows on remote

n8n-sync diff

Semantic local vs remote diff

n8n-sync status

Drift detection across workflows

n8n-sync list

Remote workflows with IDs & tags
